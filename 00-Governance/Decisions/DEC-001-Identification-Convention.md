## Contexto

El Smart Framework™ está compuesto por diferentes módulos metodológicos,
técnicos y de conocimiento.

Para facilitar su referencia, documentación, versionado y futura
automatización, es necesario establecer una convención estable de
identificación.

## Decisión

Cada módulo del Smart Framework™ tendrá dos identificadores complementarios:

1. Un identificador técnico permanente con formato `SF-XX`.
2. Un nombre funcional permanente con formato `Smart XXX™`.

Ambos forman parte de la identidad del módulo y no deben considerarse
alternativas entre sí.

## Convención

| Identificador | Nombre |
|---|---|
| SF-00 | Smart Method™ |
| SF-01 | Smart Discovery™ |
| SF-02 | Smart Brief™ |
| SF-03 | Smart Intelligence™ |
| SF-04 | Smart Solution™ |
| SF-05 | Smart Build™ |
| SF-06 | Smart Quality™ |
| SF-07 | Smart Deploy™ |
| SF-08 | Smart Knowledge™ |
| SF-09 | Smart Brand™ |
| SF-10 | Smart Research™ |
| SF-11 | Smart Platform™ |

## Uso

El identificador técnico se utilizará principalmente para:

- referencias internas;
- documentación;
- versionado;
- relaciones entre artefactos;
- automatización;
- futura integración con agentes y sistemas de conocimiento.

El nombre funcional se utilizará principalmente para:

- comunicación humana;
- documentación conceptual;
- presentación de procesos;
- comunicación comercial cuando corresponda.

## Ejemplo

La referencia completa de un módulo será:

> SF-06 — Smart Quality™

No deberá utilizarse únicamente `SF-06` cuando el contexto pueda generar
ambigüedad para una persona.

## Consecuencias

Esta decisión establece una nomenclatura estable para el Framework y evita
la creación de nombres alternativos para conceptos que ya tienen una
denominación aprobada.

Los nuevos conceptos deberán integrarse en la estructura existente siempre
que sea posible.

La creación de nuevos módulos o denominaciones deberá justificarse mediante
una decisión documentada.
