- `DEC-002` — Knowledge First
- `DEC-003` — Project Learning
- `DEC-004` — Framework Vocabulary
- `GOV-001` — Smart — Modelo Empresarial

- `GOV-005` — Smart Framework — Lexicon

### Alcance

Esta versión establece:

- identidad del Smart Framework™;
- modelo empresarial conceptual de Smart;
- misión;
- visión;
- principios;
- vocabulario controlado;
- convenciones de identificación;
- principios de conocimiento y aprendizaje.

Esta versión no constituye todavía la metodología operativa completa.

La construcción de `SF-00 — Smart Method™` y los módulos posteriores continuará
mediante validación progresiva.
